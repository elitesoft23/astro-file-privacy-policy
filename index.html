EliteFile — Privacy Policy

Effective date: May 22, 2026 • Version 1.0.0

This Privacy Policy explains how EliteFile collects, uses, and protects information when you use the App. For support or privacy requests contact: elitesoft23@gmail.com.

What we collect

  • Device & usage data: app version, device model, basic counters for diagnostics.
  • Files & media: accessed only when you browse/open files; processed locally unless you explicitly share them.
  • Network credentials: SMB/FTP/SFTP credentials you provide are stored locally if you save them; the App does not transmit them elsewhere by default.
  • Installed apps: may read installed app list for "open with" features.
  • Telemetry: opt-in counters for connection/transfer health stored locally only.

How we use data

To deliver the App features (file browsing, network connectivity, previews, sharing), store user server configs locally, and optionally store local telemetry for troubleshooting when you opt in.

Security

We use reasonable measures to protect local data. Network security depends on the protocol: prefer encrypted protocols like SFTP (SSH). Plain FTP/SMB may be unencrypted.

Permissions

  • Storage (read/write) — for file management
  • Install packages — optional, for installing APKs
  • Network & location — to access network state and Wi‑Fi details on some Android versions
  • Notifications — to post important updates (Android 13+)

Data retention & deletion

Saved servers and telemetry are stored locally. To delete data: remove saved servers in the App, clear App storage via Android Settings, uninstall the App, or email elitesoft23@gmail.com with a deletion request.

Children

The App is not intended for children under 13. We do not knowingly collect children's personal information.
